# Proposal: reusable component foundations

## Why

The project already contains the foundational tax-year, document, FX, registry, and domain-calculation components. Record their existing status separately so future delivery changes can depend on them without treating them as newly proposed behavior.

## What Changes

- Record the inspected foundation status.
- Keep application code unchanged.

## Capabilities

No specification delta: this is a historical baseline, not a new behavior change.

## Impact

Provides context for the three delivery changes. It does not authorize implementation or declare an integrated workflow complete.
